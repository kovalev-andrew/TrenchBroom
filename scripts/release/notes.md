## English

ReyondBroom combines TrenchBroom 2026.2, Fracture, Perforate, Bullet Settle and the extended editing tools from UltimateTrenchBroom.

- **Windows x64:** download `ReyondBroom-Windows.zip`, extract once and run `TrenchBroom.exe`. This is the verified build from commit `51242db7e8f0a6d86ef2f09d36b0fb485b1baa8a`.
- **Linux x86_64:** when the Linux build finishes, `ReyondBroom-Linux-x86_64.AppImage` will appear below. Built on Ubuntu 24.04; Qt is bundled. Run `chmod +x ReyondBroom-Linux-x86_64.AppImage`, then launch it. If FUSE is unavailable, use `./ReyondBroom-Linux-x86_64.AppImage --appimage-extract-and-run`.
- SHA-256 checksum files accompany the downloads. Exact build sources and Qt versions are recorded in the included build metadata.

## Русский

ReyondBroom объединяет TrenchBroom 2026.2, Fracture, Perforate, Bullet Settle и дополнительные инструменты UltimateTrenchBroom.

- **Windows x64:** скачайте `ReyondBroom-Windows.zip`, распакуйте и запустите `TrenchBroom.exe`.
- **Linux x86_64:** после завершения сборки ниже появится `ReyondBroom-Linux-x86_64.AppImage`. Сборка на Ubuntu 24.04, Qt включён. Разрешите запуск командой `chmod +x ReyondBroom-Linux-x86_64.AppImage`. Если FUSE недоступен, запустите с параметром `--appimage-extract-and-run`.
- Рядом доступны контрольные суммы SHA-256; точные версии исходников указаны в метаданных сборки.
