# Ultimate Trench Broom 0.4

Windows x64 release of the extended TrenchBroom fork.

## Highlights

- Live Terrain and Generate Rock tools, including square/triangular terrain cells and hollow rocks.
- Polygon Cut/Spawn, multi-edge Bevel, Inset, Spin, Bezier Bend, Sculpt, Subdivision, cleaner Subtract 2, and triangulated-brush cleanup.
- Random, line/star, and radial arrays; multi-sided symmetry with linked editing and undo.
- Rotated grids and snapping, automatic integer snapping, and editable viewport coordinates.
- Prefab collections, EntityList, browser zoom, PNG/JPG texture folders, palette configuration, and texture refresh.
- Unity level-prefab export with texture alignment, scale control, and optional individual brush children.
- Quake-style lighting/sky previews, door/button/lift/train previews, intermission-camera preview, and Spawn Master.
- English visual documentation: 32 topics and 95 screenshots captured in the editor.
- New green application icon and UltimateTrenchBroom executable name.
- Experimental MCP bridge removed from the application and source.

## Download and Run

Extract `UltimateTrenchBroom-v0.4-Windows-x64.zip` and run `UltimateTrenchBroom/UltimateTrenchBroom.exe`. Keep all DLLs and resource folders alongside the executable.

Game assets and map compilers are not bundled. Back up maps before using the new geometry tools.
