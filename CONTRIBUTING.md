# Contributing to ReyondBroom

**English** · [Русский](CONTRIBUTING.ru.md)

ReyondBroom is maintained independently. Target this repository and its `ReyondBroom` branch for changes, documentation and reproducible problem reports.

## Report a problem

Include the release version or build-info.json commit, operating system, selected game and map format, exact steps, expected behaviour and actual result. Attach a minimal map and a screenshot when they help. Crash reports and recovered maps are normally saved beside the map; inspect them for personal paths before sharing. Use the repository's available discussion/review channels or contact its maintainer.

## Propose a change

Explain the user-visible problem and scope. For substantial work, discuss the approach with the maintainer first. Keep changes focused, preserve source notices and compatible licensing, and follow [AGENTS.md](AGENTS.md). Build instructions are in [BUILD.md](BUILD.md).

Run relevant tests for code changes. Update the English documentation first and matching Russian translations. Check documented controls against the current editor. For handbook changes, follow [docs/README.md](docs/README.md) and inspect the generated site before publishing.

## Responsibility

Contributors are responsible for reviewing and understanding their changes, including work produced with assistance tools. Submissions must comply with the project license and must not introduce incompatible third-party material. Preserve original attribution in reused source and legal notices.
