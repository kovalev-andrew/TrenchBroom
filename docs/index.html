Terrain

Turns a flat brush into adjustable terrain with a live height preview.

Tools > Generate Terrain | Shift + T

Polygon Cut

Cuts a closed, hand-drawn shape out of the selected brush.

Tools > Polygon Cut Tool | Shift + C

Polygon Spawn

Builds new brushes from a closed outline drawn on a brush surface.

Tools > Polygon Spawn Tool | Shift + F

Bevel Tool

Rounds selected brush edges with adjustable width, segments and curvature.

Tools > Bevel Tool | Shift + B

Bevel Mouse Controls

Adjusts an edge bevel directly with mouse gestures and modifier keys.

Edge Tool | E

Inset Tool

Creates a smaller face inside one selected face, surrounded by a brush border.

Tools > Inset Tool | Shift + I

Spin Tool

Extrudes selected faces into a segmented chain that follows a movable end handle.

Tools > Spin Tool

Bezier Bend

Bends a brush group along an editable curve, with position, rotation and scale handles.

Tools > Bezier Bend Tool

Subdivision

Splits brushes into smaller pieces by segment count or grid size.

Tools > Subdivision Tool

Subtract 2

Subtracts cutter brushes while preferring straight, clean boundaries between the remaining pieces.

Edit > CSG > Subtract 2

Convert Triang Brushes

Rebuilds triangulated brush faces into simpler surfaces while preserving the overall shape.

Edit > Convert Triang Brushes | Ctrl + Shift + B

Generate Rock

Turns a brush into a seeded rock shape, optionally hollow or grouped.

Tools > Generate Rock

Sculpt Tool

Raises, lowers or smooths brush surfaces while keeping shared vertices together.

Tools > Sculpt Tool

Array: RandomRadius

Scatters copies of one object or group within a seeded random radius.

Tools > Array Tool

Array: Line

Places copies in one or more lines with adjustable spacing and offsets.

Tools > Array Tool

Array: Radial

Arranges copies around a circle or across multiple concentric rings.

Tools > Array Tool

Grid Rotation

Rotates the brush surface grid and its snapping direction.

Tools > Grid Rotation

Auto Integer Snap

Automatically snaps new and edited brush vertices to whole-number coordinates.

Toolbar > Snap Int

Edit XYZ Coordinates

Moves a selected brush, face, edge or vertex by entering exact coordinates.

Viewport > XYZ panel

Symmetry

Repeats edits around one chosen centre object across matching sectors.

Tools > Symmetry Tool

Prefab Collections

Loads named groups from map collections and places them as reusable objects.

Right inspector > Prefabs

EntityList

Finds named entities and groups, then focuses the viewport on a chosen result.

Right inspector > EntityList

Material Browser Controls

Changes texture preview size and collapses or expands material collections.

Right inspector > Face

Add a Texture Folder

Loads PNG and JPG folders as usable textures and generates their compile WAD.

Material Browser > Settings > Add Texture Folder

Choose an Export Palette

Chooses and previews the colour palette used when exporting texture folders to WAD.

Material Browser > Settings > Pallete

Entity Browser Zoom

Changes entity model preview size for easier browsing and selection.

Right inspector > Entity

Sync a Map to Unity

Exports map geometry and textures into a Unity prefab with an adjustable scale.

Unity > Sync Map...

Quake Lighting & Sky Preview

Shows an approximate Quake lighting and animated sky preview inside the editor.

View > Preview Quake Lighting

Door, Button & Lift Preview

Previews door, button and lift movement using their current entity settings.

Select entity > Play above XYZ

func_train Preview

Previews a func_train moving through its linked path_corner route.

Select func_train > Play above XYZ

Intermission Camera Preview

Shows the view from a selected info_intermission camera before compiling the map.

Select info_intermission

Spawn Master

Builds a reusable teleport closet that spawns a chosen entity when a trigger activates.

Tools > Spawn Master
