# Документация ReyondBroom

[English](README.md) · Русский

[Руководство пользователя](https://reyond9079.github.io/ReyondBroom/index.ru.html) · [Полный справочник (EN)](https://reyond9079.github.io/ReyondBroom/reference.html)

Исходник руководства — `src/handbook.json`. Каждая глава содержит английский и русский текст, путь к инструменту, последовательность действий, ограничения и пути к снимкам. Основная версия — английская. `site.css` и `site.js` отвечают за адаптивное оформление, навигацию с клавиатуры и локальный поиск. Аналитика и внешние шрифты не используются.

Установите Python 3 и Pandoc, затем выполните из корня репозитория:

```sh
python -m pip install -r docs/requirements.txt
python scripts/build-handbook.py --output _site
python -m http.server 8765 --directory _site
```

Откройте `http://localhost:8765`. Сборка проверяет локальные ссылки, якоря, изображения и альтернативные описания. Каталог `_site` создаётся автоматически; не редактируйте его вручную. `docs/index.html` — входная страница в репозитории, полный сайт публикуется процессом Pages.

Полный справочник формируется из `app/TrenchBroom/resources/documentation/manual`. Сборка адаптирует текст и инструкции по обновлению и поддержке, сохраняя примеры кода, внутренние имена файлов и исходные уведомления. Таблица `src/reference-shortcuts.js` получена из версии `f12556d`; обновляйте её из собранного редактора при изменении меню или клавиш по умолчанию.

Перед публикацией проверьте обе языковые версии, поиск, навигацию, подстановку команд справочника, широкий и узкий экран и несколько изображений в полном размере. Поддерживайте сведения об источниках в `src/sources.html`. Используйте настоящие снимки интерфейса и сохраняйте исходные уведомления.
