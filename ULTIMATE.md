# ReyondBroom tool guide

**English** · [Русский](ULTIMATE.ru.md)

The illustrated user handbook is the current guide to ReyondBroom's editing tools. This filename is retained for existing links.

- [Geometry and terrain](https://reyond9079.github.io/ReyondBroom/#terrain): Terrain, Polygon Cut/Spawn, Inset, Spin, Bezier Bend, Subdivision, Subtract 2, Convert Triang Brushes, Rock and Sculpt.
- [Bevel and destruction](https://reyond9079.github.io/ReyondBroom/#bevel): Bevel, Fracture, Perforate and Settle.
- [Placement and precision](https://reyond9079.github.io/ReyondBroom/#array-line): Array, Symmetry, grid rotation, integer snapping and XYZ editing.
- [Assets and export](https://reyond9079.github.io/ReyondBroom/#prefabs): Prefabs, EntityList, texture folders, palettes and Unity Sync.
- [Game previews](https://reyond9079.github.io/ReyondBroom/#lighting): Quake lighting, sky, moving entities, trains, intermission cameras and Spawn Master.

Quake-specific previews depend on the selected game and assets. Settle treats func_wall brushes and visible Quake 3 patches as collision geometry. New Bevel uses convex profiles and differs from the older Edge Tool chamfer gestures. Hidden unsupported experiments are not advertised as features.
